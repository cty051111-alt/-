# 难度说明

默认强化目标为插件档位3.5–4.0，不是雅思分数。

阅读固定参照为三篇同场回忆对应题目加权平均正确率65.0555%，映射为3档；平均正确率每降低10个百分点，难度增加1档。默认阅读目标约55.06%–60.06%。

听力使用固定题库参照64.5157%，尚未完成同版本完整真题校准。计算按实际题数加权。缺失统计、重复作答比例、参与人数及考生能力均会影响可信度，只能辅助相对搭配。

旧题的个人优先级使用上次错误率，与题库群体平均正确率是不同指标。
