# IELTS Practice Planner · 雅思智能组题助手

适配九分学长考雅机考平台。

将原题库的听力、阅读和写作组合成个人练习计划，在原软件里逐篇练习、暂停续做、查看成绩。

**第三方非官方插件，与九分学长无隶属或背书关系。** 不含官方客户端、题库、音频或答案，不解锁账号权限。

| 项目 | 支持范围 |
| --- | --- |
| 插件 | 0.12.0 |
| 客户端 | 九分学长考雅机考平台 **0.9.21-rc.3**，指定文件指纹 |
| 系统 | Windows 10/11，Windows PowerShell 5.1 |
| 入口 | 原软件右下角 **智能练习** |

## 下载与安装

点击 [下载 Windows 安装包](https://github.com/cty051111-alt/-/raw/refs/heads/main/downloads/jiufen-smart-practice-0.12.0-windows.zip)。安装包及 SHA-256 校验文件位于仓库 `downloads/` 目录。

1. 完整解压，不要在压缩包内直接运行。
2. 把整个插件文件夹放进九分学长安装目录，与主程序 exe 同级。
3. 保存进度，正常退出九分学长。
4. 双击 **双击安装.cmd**，看到成功提示后重新打开软件。
5. 点击 **智能练习**。按住按钮可拖动，位置自动保存。

```text
九分学长安装目录/
├─ 九分学长考雅机考平台.exe
├─ resources/
└─ jiufen-smart-practice/
   ├─ 双击安装.cmd
   ├─ 还原安装前版本.cmd
   ├─ install.ps1
   ├─ compatibility.json
   ├─ plugin/
   └─ tools/
```

安装不需要 Python、Node.js 或其他开发工具。使用 Windows 自带 PowerShell 和 .NET 在本机添加插件。

## 功能

- 听力4篇、阅读3篇、写作Task 1/Task 2自由组合；听阅逐篇核对每科40题。
- 全新题、新旧混合、全部重做；仅提交过的题算已做，草稿不算。
- 旧题在满足条件时优先安排上次错误率较高的篇目。
- 批量组题、题型和主题搭配；同批去重，避开其他未完成卷占用的题。
- 每套独立保存进度、暂停切换、继续做题；已完成篇目可以重新练习。
- 听阅正确率、题数和用时小结；首次练习与重做分开，写作不自动评分。
- 入口支持拖动、位置记忆和窗口边界保护。

### 新选项：允许旧题补足

**“难度无法满足时，允许用做过的题补足”默认关闭。**

开启后先按原新旧模式寻找目标难度，找不到时逐步增加旧题，优先少加；结果明确显示新旧篇数。仅用于听力、阅读的全新/混合模式，不改变写作或全部重做。

| 选项 | 放宽的条件 |
| --- | --- |
| 允许用做过的题补足 | 新旧题比例，优先达到目标难度 |
| 允许备选卷 | 最终难度可偏离目标，明确标注偏差 |

两项均保留Part结构、每科40题和去重要求。候选不足、服务器异常或原题不可用时，仍可能无法组题，不会虚构题目或重复填充。

## 记录与隐私

计划按账号保存在原软件本机存储中；插件更新不主动重置已有记录。安装前自动备份原程序及Local Storage、IndexedDB、Session Storage到安装目录的 `smart-practice-backups/时间戳/`。

- **未完成试卷不自动删除。**
- 已完成插件成绩保留 **7×24小时**；关闭期间到期的记录在下次启动时清理。
- 此规则只影响插件记录，不清理原平台历史、答案或作文草稿。
- 还原仅恢复程序，不回滚学习记录。
- 本项目无遥测、无第三方数据上传；使用原客户端正常接口，登录和服务端处理由原平台负责。
- 不要将备份、令牌、账号信息或个人答题数据上传到Issues。

## 还原和兼容性

正常退出软件，双击 **还原安装前版本.cmd**，恢复本次安装前的程序。如果之前装有旧插件，还原到的是旧插件。

安装前核对客户端SHA-256和插件校验值；未知版本、未知修改、运行中的程序、损坏文件或备份失败时停止。安装后逐项验证原有资源保持一致（仅HTML入口及插件文件变化）。

客户端升级可能覆盖插件，需要重新适配。不要用旧完整 `app.asar` 覆盖新版。“适配”仅指上表的版本，不保证未来版本可用。

## 限制与难度说明

通过原软件正常单篇入口逐篇练习，不提供服务器权限限制下的整套合并提交，不自动填写或提交答案。插件无法修复官方服务超时。

难度根据题库群体平均正确率及固定参照近似计算，**不是雅思分数或官方等值校准**；听力尚未完成完整同版本真题校准，不保证真实考试成绩。详见 [难度说明](docs/DIFFICULTY.md)。

## 开发和测试

源码位于 `plugin/`；本机安装工具位于 `install.ps1`、`tools/AsarPatch.cs`。

开发时安装Node.js后运行 `npm test`。测试用合成数据，不含个人答题记录。界面测试为 `tests/ui-smoke.cjs`、`tests/writing-ui.cjs`，另需Playwright和Microsoft Edge，后台运行，不操作用户桌面。

已验证选题、题数、去重、旧题补足、记录生命周期及模拟界面。模拟测试不代表所有真实账号、题型、网络环境均已验证。
